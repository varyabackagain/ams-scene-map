# Amsterdam scene map

Network map of the Amsterdam scene, built from the Notion base (Ams_Scene_v2: Entities, Tools, Bubbles).

- **Updates:** every night, and on demand via Actions → "Update the map" → Run workflow (the "Update the map" link on the map opens that page).
- **Source of truth:** Notion. Nothing is edited here by hand; change the base and update the map.
- **Needs:** a repository secret `NOTION_TOKEN` (Notion integration with access to the Ams_Scene_v2 page) and Pages set to "GitHub Actions".
